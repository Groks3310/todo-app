# Todo App

A simple React todo app that lets users manage daily tasks.

## Features

- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as complete
- Data saved in local storage

## Tech Stack

- React
- JavaScript
- CSS

## Getting Started

1. Clone the repo:
   git clone https://github.com/yourusername/todo-app.git

2. Install dependencies:
   npm install

3. Run the app:
   npm run dev
